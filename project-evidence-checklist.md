# Project Evidence Checklist

- [ ] Project goal and scope written clearly
- [ ] Lab environment and data source described
- [ ] Steps/commands/filters are reproducible
- [ ] Screenshots show enough context to understand the evidence
- [ ] Sensitive information, usernames, tokens, and private IP details reviewed/redacted where appropriate
- [ ] Findings separate observed facts from interpretation
- [ ] Limitations and false positives documented
- [ ] Recommendations follow from the evidence
- [ ] Tool versions/data source noted where relevant
- [ ] README updated with status and date completed
- [ ] Repository contains no secrets, real production logs, or restricted PCAPs
